# 01 · 快速开始

## 0. 前置条件

- Windows 10/11
- Python 3.11+（`psutil`）
- NSIS 3.x（`makensis.exe`）—— 只在使用 `_shared/build_launcher.py` 重编启动器时需要
- 各软件的**官方安装包**（本仓库不分发第三方二进制）

## 1. 目录长什么样

```
PortableApps/                      ← 仓库根（配方仓库）
├── _shared/                       共享工具链（构建器、审计器、PAL 源码）
│   ├── build_launcher.py          启动器编译器
│   ├── toolchain/                 PortableApps.comLauncher 源码（NSIS）
│   └── configs/
├── <包名>Portable/                每个软件一个包
│   ├── portableapps/              构建输入（源树）
│   │   ├── App/AppInfo/           appinfo.ini + Launcher/ + 图标
│   │   └── App/<程序>/            （构建时放入，已 gitignore）
│   ├── docs/  src/  LICENSE  .github/
└── docs/                          本目录

D:\Portapps/                       ← 产品根（可运行产物，仓库外，默认位置）
└── <包名>/
    ├── <包名>.exe                 启动器
    ├── update.py                  本包更新脚本
    ├── App/                       程序 + AppInfo
    └── Data/                      用户数据（gitignore）
```

**关键**：`portableapps/` 是配方，产品根里的 `<包名>/` 是成品。改配方要重编、
再同步到产品树才生效。产品根位置由 `_shared/_paths.py` 解析
（环境变量 `PORTAPPS_ROOT` > `_shared/portapps_root.txt` > 默认 `D:\Portapps`），
详见 [02 · 架构与目录规范](02-架构与目录规范.md)。

## 2. 跑一个已有的包

```bash
cd D:\Portapps\CursorPortable
CursorPortable.exe
```

首次运行会在同目录生成 `Data\`，**所有用户数据都写在这里**。
删掉 `Data\` 即回到初始状态；整目录拷到 U 盘即可带走。

## 3. 构建 / 重编启动器

```bash
# 改完 portableapps/App/AppInfo/Launcher/<包名>.ini 或 Custom.nsh 后
python <仓库根>/_shared\build_launcher.py CursorPortable

# 批量重编（对每个包调用一次，可自行套一层循环）
python <仓库根>/_shared\build_launcher.py <Pkg1>
python <仓库根>/_shared\build_launcher.py <Pkg2>
```

编译输出里 `Debug.nsh` 缺失是**预期内**的，看到它不代表编译失败；
真正的失败会是 `Error:` 行或非零退出码。

## 4. 新建一个包（最短路径）

1. **先监控，后写配置**。用 ProcMon / Total Uninstall 抓真实写入点，
   再据此写 `[Environment]` 与 `[DirectoriesMove]`。**顺序反过来必然返工**。
2. 把官方安装包静态解包到 `portableapps/App/<真实目录名>/`
   （`innounp` / `7z` 均可，Joplin 那类双层解包要注意位数，见避坑手册）。
3. 写 `App/AppInfo/appinfo.ini`：`[Format] [Details] [Version] [Control]` 四段齐全，
   `ExtractIcon` **必须 ls 出真实 exe 路径，不要按包名猜**。
4. 写 `App/AppInfo/Launcher/<包名>.ini`：

   ```ini
   [Launch]
   ProgramExecutable=<真实目录>\<真实exe>
   WorkingDirectory=%PAL:AppDir%\<真实目录>
   DirectoryMoveOK=yes

   [Environment]
   APPDATA=%PAL:DataDir%\settings
   LOCALAPPDATA=%PAL:DataDir%\settings\local
   TEMP=%PAL:DataDir%\settings\Temp
   TMP=%PAL:DataDir%\settings\Temp

   [Activate]
   Registry=true
   ```

5. **不要动 ini 的编码**（中文路径必须 UTF-16LE，见避坑手册 §1.4）。
6. 重编 → 同步产品树（`portableapps/` → `<产品根>/<包名>/`）。
7. 验收：见 [05 · 验收与排查](05-验收与排查.md)。

## 5. 常用验证命令

```bash
# 静态审计（不启动任何应用，秒级出报告）
python <仓库根>/_shared\tools\audit_production.py

# 全库 3 轮启动冒烟（43 单元，约 30 分钟）
python <仓库根>/_shared\tools\smoke_3rounds.py
```

## 6. 遇到打不开怎么办

按 [04 · 避坑手册 §0 速查表](04-避坑手册.md) 对号入座，
90% 的情况能在 5 分钟内定位。
