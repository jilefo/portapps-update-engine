缺陷 4 细节：更新检测输出的操作提示曾硬编码成
`cd CursorPortable/dist/CursorPortable && python update.py`，
而该 dist 树在迁移后已不存在。改为由 `_paths.product_dir()` 解析：

```
修复前：cd CursorPortable/dist/CursorPortable && python update.py --update --execute
修复后：cd D:\Portapps\CursorPortable && python update.py --update --execute
```

已实测：新路径下 `update.py` 存在可访问，旧路径 `No such file or directory`。

> **顺带确认**：39 份 `.github/workflows/*.yml` 里的 `<Pkg>/dist/` 路径
> **不需要改**——CI 是全新克隆、没有 `D:\Portapps`，会走 `_paths` 的
> 仓库内回退布局，`<Pkg>/dist/<Pkg>` 对 CI 是正确的。同一个路径字符串
> 在"本机"和"CI"两种语境下含义不同，改之前要先确认作用域。

其中两处值得单独记：

- **单测期望值是用被测逻辑现场算出来的**——我写
  `expect = tgt.replace(old, new)`，而目标是小写盘符 `d:`，

  **把 bug 当成了正确答案**。期望值必须写手写常量。
- **`.bak-` 备份纪律**：`--fix` 重编前先 `copy2` 备份，测试后清理。
