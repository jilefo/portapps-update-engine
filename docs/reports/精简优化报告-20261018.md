# 精简优化报告（制作残留与重复脚本治理）

- 生成时间：2026-10-18 10:20
- 触发问题：**「为什么有些目录里有 `_制作素材` 目录？」**
- 范围：39 个包全量排查，不止 `_制作素材` 一个名字

---

## 1. 直接回答：`_制作素材` 是什么

它是**制作便携版时的取证快照**，做完就没用了：

| 内容 | 说明 | 问题 |
|---|---|---|
| `Uninstall*.exe` / `unins000.exe` / `unins000.dat` | 第三方卸载程序 | **第三方二进制**，违反"不分发二进制" |
| `*.安装.reg` / `*.卸载.reg` | 安装监控的注册表快照 | 含宿主机器信息 |
| `XX 日志 - 文件和文件夹.txt` | 文件监控日志 | 单个 12~18MB，含**本机绝对路径** |
| `_icons/#1.ico` | 图标提取缓存 | 图标早就进 `AppInfo` 了 |
| `leftover.txt` | 剩余项记录 | 几十字节，可忽略 |

**为什么只有 3 个包有**（LobsterAI / QoderCNIDE / WinClaw）：
命名不统一的历史遗留——有的包叫 `_制作素材`、**有的叫 `evidence`**（KukuAI 就是）、
有的（大多数）做完就清了。**危险正在于此**：没有统一规范，全靠人记得清。

---

## 2. 全面排查：挖出来的远不止 `_制作素材`

顺着"什么不该进仓库"这条线全库扫，共 5 类：

| # | 类别 | 位置 | 体积 | 性质 |
|---|---|---|---|---|
| 1 | 制作素材 / evidence | 4 个包 | **53.5MB** | 取证快照，含第三方卸载程序 |
| 2 | **旧版本程序备份** | `CursorPortable/dist/CursorPortable/Backups/` | **993MB** / 15157 文件 | 更新引擎留下的 3.24.18 完整备份 |
| 3 | **冗余 app.asar** | `LobsterAI` / `WinClaw` 包根 `resources/` | **841.5MB** | 与 dist 树里那份**大小完全相同**的副本 |
| 4 | 重复脚手架脚本 | 39 包 × `scripts/`+`tests/` | 218 文件 / 409.7KB | 实质只有 7 份 |
| 5 | 产物树遗留 | `Typora` 的 `innounp.exe`+`Install.bat`、`AiPyPro` 的 `_diag` | 0.65MB | 制作期解包工具 + 0 字节调试输出 |

**第 2、3 项是最危险的**：它们都在 `App\` **之外**，
`.gitignore` 的 `*/dist/*/App/*/` 规则**管不到** → 差点进 git。
尤其是 993MB 的旧备份和 841MB 的 asar。

### 重复脚手架的实测重复度

| 文件 | 份数 | 重复情况 |
|---|---|---|
| `toolchain.py` | 39 | hash **全同** |
| `package-paf.py` / `.ps1` | 36 | hash **全同** |
| `build-portable.ps1` | 39 | hash **全同** |
| `build-portable.py` / `gen-sbom.py` / `test_structure.py` | 各 39 | 差异**只有两行**：docstring 包名 + `PKG = "<包名>"` |

改一个模板要改 39 处，改漏一处就埋雷。

## 3. 优化动作

全部采用**可逆方式**（归档到仓库外，不是直接删除）：

| 动作 | 做法 | 校验 |
|---|---|---|
| 归档制作素材 | 4 个包 → `制作素材归档/<包名>/` | 逐文件 sha256 校验通过才删源 |
| 归档旧版本备份 | 993MB 同盘 move（瞬时） | move 后文件数比对，不一致自动回滚 |
| 归档冗余 asar | 先确认 dist 里有**同大小**正主才动 | 大小校验 + 冒烟 |
| 收敛脚手架 | 生成 8 个参数化通用版 → `_shared/scripts/` | 编译校验通过才删源 |
| 清理产物树遗留 | innounp / Install.bat / `_diag` | 逐项定性（确认运行期不需要） |

**收敛后的通用脚本**用法（包名自动推导：命令行参数 > 当前目录名 > `PAF_PKG`）：

```bash
python _shared/scripts/test_structure.py CursorPortable
python _shared/scripts/build-portable.py CursorPortable
```

### 顺带修掉 2 个被掩盖的误报

跑通用 `test_structure.py` 时暴露的：

1. `version.json`（更新引擎版本元数据，**有用**）曾让 CursorPortable 报 FAIL
2. WPS 的 4 个分体 `*.Portable.exe`（**多入口设计，正常**）曾让整个包报 FAIL

两者已进白名单。**这说明收敛本身有价值——统一跑一遍就发现了两份"假失败"。**
