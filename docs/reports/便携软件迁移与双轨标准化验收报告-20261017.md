## 二、迁移执行

### 2.1 关键约束：必须 move 不能 copy

迁移前 D 盘剩余空间 **36 GB**，而 39 个项目合计 **69 GB**——
复制方案会耗尽磁盘，故全部采用同卷 `os.replace` 原子重命名（不复制数据）。

### 2.2 遇到的文件占用与处理

5 个项目顶层目录被残留进程占用（`os.replace` 报 `WinError 5`）：

| 项目 | 占用进程 | 处理方式 |
| --- | --- | --- |
| BaiduNetdiskPortable | `YunDetectService.exe`（冒烟测试遗留服务） | 停止进程 → 整目录移动成功 |
| TyporaPortable | `cmd.exe /c Install.bat`（卡住的安装器） | 停止进程 → robocopy `/MOVE` 完成 |
| LobsterAIPortable | 同上（服务 + app.asar 句柄） | robocopy `/MOVE` 复制后校验 |
| WinClawPortable | `resources\app.asar` 被占用 | robocopy `/MOVE` 复制后校验 |
| KukuAIPortable | `resources\app.asar` 被占用 | robocopy `/MOVE` 复制后校验 |

**残留说明**：上述 4 个项目的 8 个锁定文件（`app.asar` 等）已完整复制到
目标目录并通过 SHA256 校验，但因句柄占用未能从 `Work\` 删除。
重启后执行 `robocopy <源> <目标> /MOVE` 或手动删除空壳目录即可清零。

### 3.2 迁移后失效的路径依赖（已修正）

原 `scripts/build-portable.py` 硬编码：

```python
MONO = REPO.parents[1]# 迁移前推导为 GreenSoftMake
builder = MONO / "Work" / "_analysis" / "build_launcher.py"
```

迁移到 `PortableApps\<项目>` 后 `parents[1]` 变为 `< Projects >`，推导失效。
现改为经 `scripts/toolchain.py` 定位公共工具链，支持四级回退：

1. 环境变量 `PAF_TOOLCHAIN`
2. `<项目>/../../_shared`（标准布局）
3. `<项目>/../_shared`
4. `<项目>/toolchain`（单项目自带）

找不到时抛错并给出修复建议，**不再静默回退到旧路径**。

### 3.3 appinfo.ini 规范化

23 个项目的 `appinfo.ini` 缺 `[Format]`/`[Control]` 段（多由官方 Launcher
Generator 生成，段布局为 `[AppInfo]/[Launch]/...`）。已统一补齐：

- `[Format] Type=PortableApps.comFormat` `Version=3.9`
- `[Control] Start=<AppID>.exe` `ExtractIcon` `Icons=1`
- `Category` 归一到PortableApps 合法枚举
- `AppID` 与目录名对齐（WPS 的 `AppId` → `AppID`）

> ⚠ 编码差异：`WPSOfficePortable` 的 `appinfo.ini` 为 **UTF-16LE带 BOM**，
> 全部解析与写入逻辑已按 BOM 逐级回退处理，保留原编码。

## 七、公共工具链（避免 39 份重复）

PAL（PortableApps.com Launcher）工具链 14 MB，若复制进 39 个项目需 546 MB。
故集中到 `_shared/toolchain/`，各项目经 `toolchain.py` 解析引用。

```
<仓库根>/
├── _shared/                     公共工具链（非项目）
│   ├── toolchain.py             工具链定位器
│   ├── build_launcher.py        启动器编译器（PAL + NSIS）
│   ├── update_engine.py         八阶段更新流水线
│   ├── gen_update_configs.py    配置生成器
│   ├── configs/*.yaml           39 份项目更新策略
│   └── toolchain/PortableApps.comLauncher/
├── AiPyProPortable/             39 个独立项目
├── ...
└── KukuAIPortable/
```

### 更新流水线

```
detect → download/ingest → extract → diff → test → stage → release（门禁） → rollback
```

强制约束：破坏性操作默认 `dry_run=True`；`Data/` 只读；状态文件原子写；
仅最新版本接收更新，保留最近 3 版以支持回滚。

**版本源诚实原则**：`version_source.type=manual` 表示尚无已实证的在线版本源，
此时由人工下载后经 `ingest` 接管，**不虚构 URL 或版本号**。
已实证的源仅 6 个：

| 项目 | 版本源 | 节奏 |
| --- | --- | --- |
| JoplinPortable | `github_releases` | monthly |
| SoloMDPortable | `github_releases` | monthly |
| ZenBrowserPortable | `github_releases` | monthly |
| CursorPortable | `api` | weekly |
| FeishuPortable | `api` | monthly |
