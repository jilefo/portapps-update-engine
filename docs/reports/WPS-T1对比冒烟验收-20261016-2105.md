## 四、过程中发现并修复的 harness 自身缺陷（非产品问题）

1. **打字吞首字符**：前两轮 Writer/Presentation 开头 "WP" 丢失、Spreadsheets 一度 A1 全空。根因是前台激活用的 Alt-trick 会按下 Alt 激活 WPS 菜单栏，首批按键被菜单吞掉；与 T1 隔离无关（两状态都复现）。修复：改用 `AttachThreadInput` 挂接前台线程输入队列后 `SetForegroundWindow`（零按键注入），打字前发一次 Esc 取消菜单。修复后三模块文本完整。
2. **保存成功不等于内容正确**：原 harness 只判文件落盘。新增保存后解压 docx/xlsx/pptx、去 XML 标签拼接纯文本并匹配目标串的硬校验（`content_verified`），杜绝"存了空壳却判 PASS"。
3. **WPSPDF 包首页 Ctrl+O 无响应**：该包首页为「WPS PDF专业版」标签主页，阅读快捷键在该页未注册；wpsPDF（WPSOffice 包）同法成功。改用启动器命令行参数直传 PDF（PAL 透传），两状态均 2.1s 打开、翻页正常。判定为 GUI 路径差异，非缺陷、与 T1 无关。
